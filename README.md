# 🧠 TOD – Your Personal Life OS

A modern, beautifully designed productivity system built with **Next.js**, **TypeScript**, **Tailwind**, **ShadCN**, **Framer Motion**, and **Local Storage–based data persistence**.
TOD brings together focus tools, project management, checklists, mindmaps, timelines, and dashboards — all in one clean UI.
